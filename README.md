Travels is a full-stack web application designed for users to create, organise, and manage their travel experiences in one place.

Registered users can create travel entries with information such as title, country, city, description, date, and multiple images. They can also manage their profile and edit their own travel content. The project includes an administration area for monitoring users and enabling or disabling accounts.

Main Features
User registration and login.

JWT-based authentication and protected routes.

Personal user profiles with avatar support.

Create, edit, and display travel entries.

Upload, view, add, and delete multiple images for each travel entry.

Personal travel gallery.

User and administrator layouts with role-based navigation.

Admin dashboard with user statistics.

User-management tools to enable or disable accounts.

Client-side form validation and backend data handling.

Purpose:

This project was developed to practice the complete flow of a full-stack application: building a React interface, creating a REST API with Express, managing data with MySQL, and implementing authenticated and role-based experiences.

It also focuses on practical CRUD operations, image uploads, protected routes, user-state management with React Context, and keeping frontend and backend code organised into reusable, feature-based modules.
